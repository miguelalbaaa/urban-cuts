# URBAN CUTS — Barbería Moderna

Sitio web demostrativo para una barbería, diseñado para presentar servicios, mostrar estilos y facilitar las consultas de potenciales clientes.

## Demo en vivo

**[Ver sitio web](https://miguelalbaaa.github.io/urban-cuts/)**

## Descripción

URBAN CUTS es un proyecto de desarrollo web que simula la presencia digital de una barbería moderna.

El diseño utiliza una estética oscura con detalles dorados, una estructura adaptable a dispositivos móviles y secciones destinadas a presentar servicios, imágenes y opciones de contacto.

## Características

* Diseño moderno y adaptable a celulares, tablets y computadoras.
* Navegación entre secciones.
* Portada con llamadas a la acción.
* Tarjetas para presentar servicios y precios.
* Sección de presentación del negocio.
* Galería de imágenes.
* Acceso a consultas por WhatsApp.
* Menú interactivo para dispositivos móviles.
* Año del pie de página actualizado automáticamente.

## Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript
* Google Fonts
* GitHub Pages

## Publicación

El proyecto está publicado mediante GitHub Pages.

Para personalizarlo para una barbería real, es necesario actualizar los datos del negocio, los precios, los horarios, las imágenes y el número de WhatsApp.

## Estado del proyecto

Proyecto demostrativo para portafolio.

Los precios, horarios, ubicación y demás datos comerciales son ilustrativos. Las imágenes son recursos de referencia y deben reemplazarse por imágenes autorizadas cuando se adapte el sitio a un negocio real.
